# Moto4D Studio 中文说明

> [English](README.md) | 简体中文

面向摩托车产品研发的开源、本地优先 4D 工程可视化工作台。围绕从 CATIA 导出的 CAD 数据，提供装配工序时间线、简易机构运动预览，以及时变网格 / 点云序列播放。桌面端（macOS / Windows），所有解析与渲染都在本机完成，**模型文件不上传任何服务器**。

## 这是什么

"4D" 在这里指在三维模型之上加入**时间维度**。Moto4D Studio 把工程上常见的三种"4D"合进一个桌面应用：

| 工作区 | 快捷键 | 解决什么问题 |
|---|---|---|
| **装配时间线** | `1` | 把总成拆成可播放、可说明、可交接的装配工序：零件姿态关键帧 + 带时间戳的工序卡（工具 / 扭矩 / 作业说明）+ 径向爆炸视图 |
| **机构运动** | `2` | 对选中部件定义单个转动副 / 移动副驱动，可编辑轴、行程、速度，实时回放运动范围 |
| **时变几何** | `3` | 按顺序播放多帧网格 / 点云文件（如扫描序列、变形快照），逐帧检查空间变化 |

首次启动自带一个 **12 零件的简化摩托车示例总成**（含 6 道工序、3 个关节、10 帧形变演示），不导入文件也能完整体验三个工作区。

## 功能一览

- **CAD 导入**：支持 STEP (.step/.stp)、IGES (.iges/.igs)、BREP。装配体名称与层级结构通过 Open CASCADE WebAssembly 运行时（`@tx-code/occt-js`）在本机解析，逐组件载入总成树。
- **工序标注**：为每个装配步骤记录时间点、作业说明、工具/工装、扭矩参数；工序在时间轴上显示为事件标记，点击跳转。
- **姿态关键帧**：选中零件 → 摆位姿 → 一键记录关键帧；播放时自动在关键帧间线性插值（位置 + 欧拉角）。
- **机构预览**：单自由度旋转副 / 移动副，正弦驱动，轴 / 最小最大值 / 速度均可编辑。
- **网格导入**：STL、OBJ、PLY、glTF、GLB。时变几何模式下多个文件按导入顺序组成离散帧；非索引 PLY 自动按点云渲染。
- **项目文件**：保存 / 重开 `.m4d`（本质是 JSON），只存时间线与项目设置，**不内嵌几何**。
- **录制**：视口预览一键录制为 WebM（VP9）。
- **跨平台打包**：同一套 Electron 应用可打包 macOS（DMG/ZIP）与 Windows（NSIS/ZIP）。

## 从源码运行

要求：Node.js 20+ 与 npm。

```sh
npm install
npm run dev          # 启动 Vite 开发服务器
```

开发桌面壳：保持上一个终端的 Vite 服务运行，另开一个终端：

```sh
npm run desktop      # 启动 Electron
```

构建安装包：

```sh
npm run dist:mac     # macOS 上构建 DMG + ZIP
npm run dist:win     # Windows 上构建 NSIS 安装器 + ZIP
```

也可以在 GitHub Actions 手动触发 `Build desktop artifacts` 工作流：会在原生 runner 上构建 Apple Silicon / Intel Mac 产物与 Windows x64 安装器并上传。**产物未做代码签名与公证。**

## 推荐工作流

1. 在 CATIA 中把总成导出为 STEP（尽量用 AP203/AP214/AP242），导入 Moto4D Studio。
2. 选中零件 → 调整位姿 → 在时间轴上添加关键帧；用「＋ 新增工序」补充安装 / 检验步骤说明（工具、扭矩）。
3. 简单单轴动作预览用「机构运动」；网格 / 点云帧序列用「时变几何」。
4. 保存 `.m4d`。它只含时间线与设置——**重新打开源模型文件后，再打开 `.m4d`**，工程会按组件路径自动重新关联设置。

技术栈：Electron 39 + Vite 7 + Three.js 0.180 + Open CASCADE (WASM)。

## 工程边界（务必阅读）

这是一个面向产品 / 工艺变更讲解与评审的早期 MVP：

- **不修改** CATIA 原生文档（不做特征树 / 参数化历史编辑），STEP 只是中性格式查看路径，保真度取决于源文件与转换器。
- **不求解**多关节运动学约束、力 / 接触 / 碰撞，没有约束图与物理求解器——机构视图只是动作预览。
- **不插值**拓扑变化的网格序列：帧与帧之间是离散切换，不做对应点推断或形变重建。
- **不构成** CATIA DMU、CAE、制造验证或法规认证结论。
- 关键帧按「装配路径上的组件名」关联——重命名或重组源装配体会导致关联失效。
- 内置演示摩托车与形变序列仅作示意，不是真实车型几何或经验证的工程数据。
